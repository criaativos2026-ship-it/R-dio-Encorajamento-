# Logo oficial

Coloque aqui o arquivo **oficial** da logo da Missão Encorajamento com o nome `logo.svg`.
Para usar PNG, mude `LOGO_SRC` no início de `js/app.js`.

- A logo é exibida com `object-fit: contain` e largura automática, então a proporção original é sempre mantida. Ela nunca é esticada nem cortada.
- Use uma versão que funcione sobre fundo branco (menu lateral) e sobre a cor principal (tela de entrada). Se houver uma versão própria para cada fundo, avise para que as duas sejam configuradas.
- Enquanto o arquivo não existir, o app mostra um espaço reservado escrito "Logo oficial". Nenhuma logo é inventada.
